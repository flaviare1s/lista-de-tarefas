# 📝 Lista de Tarefas

[🇺🇸 English Version](./README.en.md)

## 📋 Visão Geral

Aplicação web moderna de lista de tarefas com interface elegante e intuitiva. Projeto desenvolvido nos cursos da ADA (Front-end em React e Elas+Tech).

## ✨ Funcionalidades

- ✅ Adicionar novas tarefas
- ✅ Marcar tarefas como concluídas
- ✅ Remover tarefas
- ✅ Persistência de dados com LocalStorage
- ✅ Design responsivo e moderno
- ✅ Animações suaves
- ✅ Interface glassmorphism

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização com gradientes, glassmorphism e animações
- **JavaScript** - Lógica da aplicação e manipulação do DOM
- **LocalStorage** - Armazenamento local de dados

## 🎨 Destaques do Design

- Gradiente roxo moderno
- Efeito glassmorphism
- Animações suaves ao adicionar tarefas
- Feedback visual em interações
- Interface responsiva para mobile

## 💻 Como Usar

1. Clone o repositório:

```bash
git clone https://github.com/flaviare1s/lista-de-tarefas.git
```

2. Abra o arquivo `index.html` em seu navegador

3. Comece a adicionar suas tarefas!

## 📱 Responsividade

O projeto é totalmente responsivo e se adapta a diferentes tamanhos de tela, oferecendo uma experiência consistente em dispositivos móveis e desktop.
