# 📝 To-Do List

[🇧🇷 Versão em Português](./README.md)

## 📋 Overview

Modern to-do list web application with an elegant and intuitive interface. Project developed in ADA courses (Front-end in React and Elas+Tech), focusing on web development fundamentals and data persistence.

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Remove tasks
- ✅ Data persistence with LocalStorage
- ✅ Responsive and modern design
- ✅ Smooth animations
- ✅ Glassmorphism interface

## 🚀 Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Styling with gradients, glassmorphism, and animations
- **JavaScript** - Application logic and DOM manipulation
- **LocalStorage** - Local data storage

## 🎨 Design Highlights

- Modern purple gradient
- Glassmorphism effect
- Smooth animations when adding tasks
- Visual feedback on interactions
- Responsive interface for mobile

## 💻 How to Use

1. Clone the repository:

```bash
git clone https://github.com/flaviare1s/lista-de-tarefas.git
```

2. Open the `index.html` file in your browser

3. Start adding your tasks!

## 📱 Responsiveness

The project is fully responsive and adapts to different screen sizes, offering a consistent experience on mobile devices and desktop.
